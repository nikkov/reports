## Приёмка версии 1.0

**Принято постановщиком 2026-11-05.** Текущее состояние объявлено первой версией проекта.
Этапы 1–3 приняты по своим критериям, все пять пунктов DoD (ТЗ §5) закрыты, лицензионные
отклонения (libpq, catch2, zlib) согласованы.

Состав версии 1.0:

- бэкенд C++/Drogon с 5 эндпоинтами, лимитом 50 000 строк и `statement_timeout` 2 с;
- фронтенд Vue 3: свой рендерер таблиц (ADR-20), группировка любой глубины, подытоги, объединения,
  сворачивание, вычисляемые колонки, диаграммы line/bar/pie с сериями;
- параметры из БД с `ID → NAME`, мультивыбор в дропдауне с чекбоксами, каскад (ADR-22);
- 7 шаблонов в PostgreSQL (ADR-21) + экран списка отчётов;
- проверки: Catch2 13, vitest 48, покрытие `engine/` 97,6 %, golden 15/15, e2e 19, лицензии.

Известные ограничения версии 1.0 (сознательно вне объёма):

- чистая сборка «с нуля» на пустом Conan-кэше не проверялась (отложено на финал);
- шаблоны читаются из БД только на старте сервиса — hot-reload не делается;
- диаграммы не поддерживают выражения в `yField` (только поле + агрегат);
- экспорт, drill-through, планировщик рассылки, аутентификация — вне области работ по ТЗ §6.

### Дополнение 1.4.1 (замечания постановщика)

**Итог: версия 1.4.4 принята постановщиком 2026-11-05** — экспорт в Excel (сворачивание групп
по региону и категории) и печать в текущей вкладке (таблица под заголовком, объединения сохранены).
Отклонённый и откаченный вариант с отдельным окном (1.4.3) оставлен в истории как решение «не делать».

| Замечание | Причина | Подтверждение |
|---|---|---|
| «В Excel пропадает сворачивание» | уровни структуры не выставлялись | `outlineLevel`=1 у 2 748 строк, `summaryBelow=true`; e2e проверяет уровни |
| «PDF строится долго и без таблицы» | `contain: strict` схлопывал контейнер в 0 px; печать вызывалась до отрисовки строк | высота контейнера в print-медиа 71 684 px, в макете 2 755 строк; e2e |
| «Печать больших отчётов» | полный DOM на 24 000 строк | лимит 5 000, `PRINT_LIMIT` без вызова печати |
| «При печати таблица со второй страницы» | Chromium не режет таблицу с `rowspan` внутри контейнера виртуализации | печатный слой: страницы по высоте строки, шапка в каждой, объединения пересчитаны; таблица на y=90 под заголовком; 121 страница PDF; e2e |
| «Печать через всплывающее окно не подходит» (1.4.3 отклонена и откачена) | политика браузера; в окне терялись стили и объединения | вариант A: печать в текущей вкладке (`window.print()`), стили и объединения наследуются, окон 0; e2e |
| «Группировка по региону есть, по категории нет» | уровни выводились из подытогов, а подытоги только у региона | иерархия по путям групп: уровень 1 — опоры категорий (22), уровень 2 — детали (2 726); e2e проверяет оба уровня |
