# Журнал решений (append-only)

Полные формулировки ADR-1…ADR-19 — в `../../PLAN.md`. Здесь фиксируются только решения, принятые
по ходу исполнения, чтобы не переписывать план задним числом.

## 2026-11-05 · D-1. Лицензии libpq и Catch2 приняты

`libpq 15.4` (PostgreSQL License) и `catch2 3.7.1` (BSL-1.0) признаны постановщиком допустимыми,
хотя формально не входят в перечень MIT/BSD/Apache из DoD ТЗ §5. Оба permissive и OSI-совместимы;
замена libpq невозможна, замена Catch2 на `doctest` (MIT) дала бы ≈ 1 день работы без выигрыша.
Статус: **принято**. Отражено в `THIRD_PARTY.md` и в таблице DoD плана.

## 2026-11-05 · D-4. Уточнение Ф4 с постановщиком

- три шаблона-примера из ТЗ: сводная продаж, финансовый, операционный дашборд;
- документация: справочник полей, семантика выражений, пошаговая инструкция «как добавить отчёт»;
- нужен экран списка отчётов;
- **шаблоны хранятся в БД** (ADR-21), а не только в файлах;
- приёмка: чек-лист DoD ТЗ + зелёные тесты + демонстрация по ссылке;
- лицензионный аудит — только прямые зависимости (полный список транзитивных не требуют).

## 2026-11-05 · D-3. Деплой — только локальный запуск, Docker вне объёма

Решение постановщика: пока нужны только локальные демонстрации. Задача 1.11 переписана:
вместо Docker Compose — `scripts/build.sh` (сборка с нуля) и `scripts/demo.sh` (backend + preview
собранного фронтенда с проксированием `/api`, health-check, печать ссылок, корректная остановка).
Postgres остаётся внешним (`192.168.0.3:32770`), контейнер-резерв для тестов не делаем.
Пересмотр — если появится требование к развёртыванию на сервере или CI.

## 2026-11-05 · D-2. Рендерер таблиц — на выбор предложены варианты

Замеры прод-сборки показали, что узкое место — базовый рендер vxe-table (2,4–4 мс/строку), а не
`mergeCells`; страница в 200 строк занимает 0,86 с, 2 000 строк — 4,8 с. Оценка вариантов:
`docs/renderer-assessment.md`.

| Вариант | Работы | Статус |
|---|---|---|
| A. vxe + пагинация 200 (текущее ADR-19) | 0 | работает, ограничение по объёму |
| B. vxe как рендерер окна + своя витрина | 3–4 дн. | предложено |
| C. Свой лёгкий рендерер на Vue (нативная таблица) | 5–7 дн. | **рекомендация** |

Блокирует решение: ТЗ §2 называет таблицей vxe-table, вариант C — отклонение от ТЗ.
До ответа PO в коде действует вариант A.

## 2026-11-05 · D-3. Лицензии вне дословного перечня DoD — приняты

DoD ТЗ §5 требует «MIT / BSD / Apache-2.0». Ревизия по фактическим версиям (`scripts/licenses.mjs`)
показала три компонента permissive с иными именами лицензий:

| Компонент | Лицензия | Роль |
|---|---|---|
| libpq 15.4 | PostgreSQL License | клиент PostgreSQL для Drogon ORM, замены нет |
| catch2 3.7.1 | BSL-1.0 | тесты C++; альтернатива `doctest` (MIT) — ≈1 день миграции |
| zlib 1.3.1 | Zlib | gzip/deflate в Drogon, транзитивная |

Решение постановщика 2026-11-05: все три приняты как permissive и OSI-совместимые; лицензионных
блокеров для приёмки нет. Список и обоснования зафиксированы в `THIRD_PARTY.md`, проверка
автоматизирована шагом `check.sh` («Лицензии прямых зависимостей»).
